# nbs-issue-tracker

The public issue and progress tracker for NBS

Please note: at this time we are only accepting bug reports for brawlers we have marked as done, please ensure you follow the checklist when reporting a bug

To begin, please select a form [here](https://github.com/nbsmod/nbs-issue-tracker/issues/new/choose)

### For modders:

See also the csv wiki, which tracks what columns we have implemented.

If a csv is missing, it means either we haven't implemented it, or it has no effect on game logic.

If a column is marked done, but behaving incorrectly please make an issue.

## Brawlers

* ✔ - Implemented, may not be perfect
* \* - Noticeable issues, feel free to make an issue describing what exactly is wrong
* ✘ - Not done, not accepting issues (this is to prevent the issue tracker from being flooded)
